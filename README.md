# ExecCap Advisors - Multi-page website concept

This is a rebuilt front-end concept for ExecCap Advisors. It turns the original card-based mockup into a more specific ownership story: an executive defines the owner they want to become, tests the transition, aligns capital, and prepares for the first 100 days.

## Pages

- `index.html` - story-led home page and audience routing
- `eta-path.html` - scroll-linked five-stage ETA journey
- `business-owners.html` - successor and transition story
- `capital-partners.html` - operator readiness, fit, alignment, and governance
- `insights.html` - editorial field notes with a featured article
- `contact.html` - warm, qualification-oriented fit conversation

## Run locally

From this folder, run `python -m http.server 4173`, then open `http://127.0.0.1:4173/index.html`.

The form is intentionally front-end only. Connect it to the approved intake, privacy, and response workflow before production launch.
