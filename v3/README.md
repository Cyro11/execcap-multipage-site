# ExecCap Advisors / Refined Edition 3

Updated in place at /v3/ following the owner's request for a simple, elegant, polished website. Earlier editions remain at the repository root and /v2/. The previous Edition 3 is retained in Git history at commit 8be7d30cc7c0813e5d4263c560cb49b1fd88c4c3.

The design uses restrained photography, editorial layouts, the original ExecCap colors/type, and gentle scroll reveals. The former diagrams, interactive lenses, and cross-page transitions have been removed. See DESIGN_SYSTEM.md and ASSET_CREDITS.md.

The shared footer uses a pale blue woven texture, a prominent contact area, grouped navigation, and the official LinkedIn logo. Diagonal link arrows have been removed throughout. Four firm capabilities meet at a central diamond on larger screens and stack on phones. Insights uses image-led field notes, with matching article headers. A linked learning feature fills the empty area beside the internship signup preview. Photography also gives the main client and process pages a consistent visual anchor.

Internship signup remains a clearly labeled preview without saving or sending information. Contact prepares an email draft for visitors to review and send. Forms are disabled if JavaScript is unavailable, with a direct email fallback.
